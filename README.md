# 마지막 수확 · The Last Harvest

아일랜드 대기근을 배경으로 한 한국어 브라우저 생존·사회 관리 게임입니다. 가상의 서부 해안 마을 **킬모라**의 행정관으로 1845년 1월부터 1852년 12월까지 96개월 동안, 처음의 1,200명 중 최대한 많은 사람을 살려냅니다.

## 바로 실행

`play.html` 또는 Windows의 `start-game.cmd`를 더블 클릭하세요. 최신 Edge·Chrome 등에서 서버나 패키지 설치 없이 실행됩니다. 이미 게임을 열어 놓았다면 새로고침하세요.

개발용 서버는 Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```powershell
cd games/last-harvest
node server.mjs
```

<http://127.0.0.1:8765/>를 엽니다. 종료는 터미널에서 `Ctrl+C`입니다. 개발용 `index.html`은 HTTP 서버를 통해 사용하고, 직접 열 때는 `play.html`을 사용합니다. 기존 공동 지도 앱과 독립적인 폴더·포트이며 지도 데이터와 API를 사용하지 않습니다. 서버는 이 컴퓨터의 `127.0.0.1`에만 연결됩니다.

## 한 달의 결정

1. 책상 위 공문, 팝업으로 나타나는 주민 사연, 폭동에 응답합니다. 개인 사연과 폭동은 답해야 다음 달로 진행됩니다. 팝업을 닫고 먼저 장부를 확인할 수도 있습니다.
2. 행정 조치 2회로 구호·경작·거처·의료·이민 등을 시행합니다. 같은 조치는 한 달에 한 번만 가능합니다.
3. 배급률, 곡물 수출, 가축 대납을 정합니다.
4. 월말 사망·질병·축출·징벌 예상을 확인하고 한 달을 마감합니다.

지도 건물을 누르면 관련 규칙을 읽을 수 있습니다. 왼쪽 메뉴에서 자원 장부와 전체 행정 기록을 확인하고 UTF-8 텍스트로 기록을 내려받을 수 있습니다.

## 서로 이어지는 재난

| 시스템 | 당장의 효과 | 대가와 후속 결과 |
| --- | --- | --- |
| 감자·씨감자 | 9월 수확으로 주민 식사 확보 | 1846년 마름병으로 기본 수확 300 → 8. 씨감자 손실은 이후 수확도 감소 |
| 수출 창고 개방 | 봉인 곡물을 주민 식량으로 전환 | 소유권 침해로 압력 증가, 미납 시 축출 |
| 구빈원 | 60명씩 최대 240명 수용, 정부 기금·수용자 몫 식량, 겨울 거처 | 가족 분리로 사기 감소. 120명 초과부터 과밀 위험 가중 |
| 공공근로 | 정부 기금 £32와 월말 식량 4단위 | 도로 포장·돌 깨기로 영양 결핍 +6, 노동 부담 +18, 발열 위험 +6, 사기 −4 |
| 발진티푸스 | 구빈원 과밀·노동 부담·영양 결핍의 누적 결과 | 발열 위험 35 이상에서 질병 사망. 식량이 충분해도 전염병 피해가 남을 수 있음 |
| 격리·세탁·휴식 | 발열 위험 −22, 노동 부담 −12 | 기금 £24와 사기 −2. 진료소도 위험·질병 사망을 완화 |
| 이민선 | 떠난 주민은 마을 식량을 소비하지 않음 | 항해 사망, 남은 가족의 사기·행정관 평판 손상. 도착 전까지 생존 확정 아님 |
| 식량 폭동 | 발포로 진압하거나 창고 약탈을 감수 | 발포는 즉시 민간인 사망. 방관 시 월말에 구빈원 밖 모든 주거지 축출 |

식량 1단위는 50명의 한 달 식사입니다. 지주 곡물과 가축은 자동으로 배급되지 않습니다. 곡물을 수출하지 않고 유보해도 봉인 창고에 남으며, 별도의 개방 명령이 필요합니다.

소작료 할당량은 월 22단위, 1847년부터 26단위입니다. 가축 1마리는 곡물 4단위를 대납합니다. 미납 비율에 따라 최대 54명이 축출됩니다. 월말 압력 65 이상이면 기금 최대 £30·곡물 최대 20단위를 압수하고 최대 45명을 추가 축출합니다. 할당량 완납은 압력을 5 줄입니다.

사회 불안 65 이상, 또는 영양 결핍 70 이상과 사기 42 이하가 겹치면 폭동이 발생합니다. 선택 후 4개월은 재발을 유예합니다. 방관에 대한 집단 축출은 별도 보복 규칙이며 평소의 최대 54명 제한을 적용하지 않습니다. 거처를 미리 마련해도 그 월말의 집단 축출을 취소하지는 못합니다.

## 이민과 최종 집계

- 북미행: 기금 £48, 최대 60명, 2개월. 기본 1인당 해상 사망 위험 26%에 출항 당시 영양 결핍을 반영합니다.
- 호주 지원 항로: 1848년부터, 기금 £82, 최대 40명, 4개월. 기본 위험 6%에 영양 결핍을 반영합니다.
- 추가 보급 £24로 사망 위험을 55% 줄일 수 있습니다. 선박 마련은 3개월 간격입니다.
- 각 승선자의 결과는 도착 때 개별 확률 판정합니다. 난수 상태가 세이브에 포함되어 같은 진행을 새로고침해도 결과가 바뀌지 않습니다. 새 게임은 별도의 난수 상태로 시작합니다.
- **마을 주민 + 해외 정착 + 항해 중 + 총 사망 = 1,200명**을 항상 유지합니다. 해상 사망과 발포 사망은 총 사망에 포함합니다.
- 1852년 12월에도 항해 중인 주민은 결말 미확인으로 따로 표시하며, 정착 생존자로 더하지 않습니다. 마을 주민이 0명이어도 항해 중인 선박이 있으면 도착을 기다립니다.

항로의 비용·정원·기간·확률은 **게임용 수치**입니다. 실제 역사 통계가 아닙니다. 최종 결과는 확인 생존(마을+정착), 항해 중, 총 사망 및 사망 유형을 나누어 보여줍니다.

## 개인 서사와 연출

노라의 씨감자 절도, 패트릭의 공공근로, 메리와 딸의 병동 분리, 발열 병동, 이민자를 보낸 가족의 빈자리 등이 상태에 따라 나타납니다. 선택은 식량·종자·기금·사기·평판·질병·거처에 반영되고 기록에 남습니다. 모두 가상 인물과 사연입니다.

지도는 채도를 낮춘 색, 차가운 비와 바다 안개를 사용합니다. 주민의 SVG 체형과 자세는 영양 결핍에 따라 앙상하고 굽은 모습으로 변하고 인구가 줄면 지도에 보이는 주민 수도 감소합니다. 2D SVG 연출이며 3D 캐릭터 모델은 아닙니다. 지도 아래 ‘비 연출’을 끄면 비·주민 움직임을 멈춥니다. 시스템의 동작 줄이기 설정도 따릅니다.

## 저장

같은 브라우저·주소의 `localStorage`에 선택마다 저장됩니다. 기존 버전의 기록을 자동으로 새 규칙으로 옮기며, 덮어쓰기 전 `last-harvest-v1-backup` 키에 이전 저장을 보관합니다. 이전 플레이의 선택과 사망을 새 규칙으로 소급 재계산하지 않습니다.

파일을 직접 연 게임과 서버 주소에서 연 게임은 별도 저장됩니다. 파일 이동, 브라우저 변경·설정에 따라 저장소가 달라질 수 있습니다. 브라우저 데이터 삭제나 시크릿 창 종료 시 기록이 사라질 수 있습니다. 기록 내려받기는 일지이며 세이브 파일 불러오기는 아닙니다. 저장이 막히면 화면 상단에 표시합니다. 새 기록은 게임 안에서 확인 후 기존 저장을 대체합니다.

## 역사적 범위와 자료

킬모라, 개인 인물, 수치와 행정관에게 집중된 권한, 일률적인 할당량·자동 축출·군경 징벌·폭동 보복은 가상 규칙입니다. 씨감자 절도를 이유로 반드시 추방해야 했다는 법률을 재현하지 않습니다. 실제 마름병은 1845년에 시작되었으며, 게임은 1846년의 큰 피해와 구분합니다.

‘관선(棺船, Coffin Ship)’은 정부 선박이라는 뜻이 아니라 관에 빗댄 표현입니다. 북미의 일부 열악한 항해와 호주의 정부 감독 항로를 같은 조건으로 일반화하지 않습니다. 호주 국립박물관의 설명을 참고해 게임에서도 항로 조건을 달리했습니다. 구빈원·노동만이 유일한 구호 형태였던 것도 아니므로 기존의 청원·수입·급식 지원을 함께 둡니다. 발진티푸스를 나타내는 발열 위험은 질병 환경을 압축한 지표이며 의학 모형이 아닙니다.

- [아일랜드 국립기록원: 대기근 자료 안내](https://www.nationalarchives.ie/topics/famine/Great_Famine.pdf)
- [아일랜드 대기근 박물관: 구호·질병·이민](https://www.ighm.org/learn.html)
- [호주 국립박물관: 이민 항로와 조건](https://www.nma.gov.au/exhibitions/not-just-ned/background)
- [UCD: 대기근기 에니스킬런 구빈원 연구](https://researchrepository.ucd.ie/bitstreams/d1bb85a4-0f0f-453a-a543-688e916d0507/download)
- [History Ireland: Food Exports from Ireland 1846–47](https://historyireland.com/food-exports-from-ireland-1846-47/)
- [Irish Historical Studies: The Irish grain trade, 1839–48](https://www.cambridge.org/core/journals/irish-historical-studies/article/abs/irish-grain-trade-183948/A1F5D0804E3F3AB283D9228F80171D43)

지도·건물·주민은 프로젝트에서 작성한 SVG입니다. Google Fonts를 불러올 수 없으면 시스템 한글 폰트로 대체됩니다. 게임 로직과 저장은 외부 서비스에 의존하지 않습니다.

## 개발과 검증

| 파일 | 역할 |
| --- | --- |
| `engine.js` | 월별 모형, 이민·질병·폭동·서사, 난수와 저장 검증 |
| `ui.js` | 조작, 팝업, 로컬 저장 이전, 결말과 기록 내보내기 |
| `map.js` | SVG 마을·주민·비 연출 레이어 |
| `styles.css`, `index.html` | 반응형 화면과 접근 가능한 컨트롤 |
| `play.html` | 바로 열어 실행하는 배포본 |
| `build-standalone.mjs` | 원본에서 배포본 재생성 |

```powershell
node --test tests/engine.test.mjs tests/hardship.test.mjs
node tests/balance.mjs
node build-standalone.mjs
```

계산 테스트 29개는 봉인 자원, 수확, 축출·징벌, 이민 사망·정착·항해 중 집계, 과밀·노동·질병, 폭동의 양쪽 결과, 씨감자 선택, 소규모 가족의 겨울 노출, 저장 이전과 인구 보존을 검사합니다. 비교 시뮬레이션은 전략별 게임 결과를 점검하며 실제 역사적 생존율을 추정하지 않습니다.

Playwright가 설치된 환경에서 `node tests/browser.mjs`로 화면과 조작을 검사할 수 있습니다. `PLAYWRIGHT_MODULE`은 패키지 모듈 URL, `BROWSER_PATH`는 브라우저 실행 파일, `GAME_URL`은 서버 또는 `play.html`의 파일 URL을 지정합니다. 별도 프로필에서 검사하므로 플레이어의 저장을 바꾸지 않습니다. 스크린샷은 Git에서 제외한 `qa-output/`에 생성합니다.
